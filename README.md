Flipkart Homepage Clone
This project is a Flipkart Homepage Clone created using HTML and CSS. The purpose of this project was to practice and improve my front-end development skills, especially Flexbox layout properties for responsive and structured webpage design.

Features :
- Flipkart-inspired homepage UI
- Built using HTML5 and CSS3
- Implemented Flexbox for layout alignment and responsiveness
- Clean and structured design
- Navigation bar, banners, product sections, and styled components

Technologies Used : 
- HTML5
- CSS3 (Flexbox)

Purpose of the Project :
This project was created for learning and practicing frontend web development concepts, particularly:
- Page structuring with HTML
- Styling with CSS
- Layout management using Flexbox
- Improving UI designing skills

Future Improvements :
- Add JavaScript for interactivity
- Make the page fully responsive for all devices
- Add animations and hover effects
- Implement backend functionality for a complete e-commerce experience
